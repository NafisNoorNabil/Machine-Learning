# Amazon Product Review Sentiment Analysis

A machine learning project that uses Natural Language Processing (NLP) to classify Amazon product reviews as **Positive, Neutral, or Negative** based on customer ratings and review text.

## Technologies Used
- Python, Pandas, NumPy
- Scikit-learn
- TF-IDF Vectorization
- Matplotlib, Seaborn
- Joblib

## Methodology
- Clean and preprocess review text.
- Convert text into numerical features using TF-IDF.
- Train and compare five classifiers: Multinomial Naive Bayes, Logistic Regression, Linear SVC, Decision Tree, and Random Forest.
- Evaluate models using accuracy, macro F1-score, classification reports, and confusion matrices.
- Explore cross-validation, hyperparameter tuning, and class imbalance handling.

## Sentiment Labels

| Rating | Sentiment |
|---|---|
| 1–2 stars | Negative |
| 3 stars | Neutral |
| 4–5 stars | Positive |
